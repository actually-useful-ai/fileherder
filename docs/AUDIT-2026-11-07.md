# Fileherder package, safeguards and reuse audit

November 7, 2026. Canonical owner: `actually-useful-ai/fileherder`, MIT. Source
baseline `cedd2ec42d822af9fe800d7eeb24d59b7f5cea5d`. The origin is public;
all audit changes remain on local branch `audit/file-safeguards-20261107`.
Nothing was pushed, uploaded, published or changed in the existing release.
This is a software audit using authored temporary files, not a cleanup of
owner data or a guarantee about every filesystem/concurrent writer.

## Reproduced findings and private corrections

| Baseline finding | Correction in this branch |
| --- | --- |
| `overwrite=False` missed dangling links; copy followed one and wrote outside the destination. Move replaced the link entry. | Links count as occupied entries; conflict numbering preserves them. Explicit overwrite refuses links/directories. |
| Rename accepted absolute names and `../` or nested paths. | Rename accepts a single native filename; invalid names fail without moving the source. |
| Mutation helpers accepted directories/source links; dry runs could report success for inputs that could not safely be applied. A move to its own parent unexpectedly renamed the source. | Regular-file-only mutation inputs; validation also applies to dry runs. Same-file moves fail; copy suffix behavior is preserved. |
| Organization followed a category-directory link outside the requested root and reported success after a failed move. | Preflight category entries, reject direct links/non-directory entries, and retain truthful partial counts/error status. |
| `chunk_size=0` hashed no bytes, grouping different nonempty files as duplicates. | Require a positive, non-boolean integer before reading. |
| A symlink could become the nominal retained member of a duplicate group. | Duplicate scanning excludes symlink representatives. |
| CLI deletion used a stale scan through a confirmation delay; a changed candidate or missing/changed keeper did not stop unlink. Delete failures were not propagated. | Confirm once, then rehash the keeper and every member against the scanned digest. Recheck before each unlink; reject stale/invalid groups and return failure status. |
| A requested deletion without Rich silently returned success while doing nothing. | Report the missing optional CLI dependency and return failure. |
| Declared Python 3.8 support failed during import with evaluated built-in generic annotations. | Postpone annotations; execute the complete suite on Python 3.8.20. |
| Import `__version__` was 1.0.0 while distribution metadata was 1.0.2. | Align the import value with package metadata. This is not a new release. |

The new CLI regression also exposed a looped-link exception in the first guard
implementation. The final guard refuses it without deleting or crashing.

## Fresh validation and its limits

- Original clean source: **50 tests passed** on Python 3.12.15.
- Published no-dependencies wheel: the **same 50 tests passed** outside the
  checkout using isolated Python and pytest importlib mode.
- Initial operation-safeguard regressions: 50 failures out of 64 cases before
  fixes. Initial seven CLI cases also failed, including actual loss of an
  authored candidate after keeper/candidate changes at confirmation.
- Final private source: **125 tests passed on Python 3.8.20 and 3.12.15**.
  These are 125 cases across two interpreters, not 250 independent cases.
  All sentinel/escape paths remain inside temporary test roots.
- Patched wheel/source-archive checks, installed-wheel suite, overlap regression
  results and final source/commit hashes are retained in the private harvest
  evidence ledger. They are separate from the published artifacts above.

The published Python 3.8 import failure was reproduced with a project-local
interpreter before applying the annotation fix. Only local audit environments
and authored files were created. No device, model, service or user-file scan ran.

## Reuse owners and overlap corrections

| Responsibility | Existing owner | Disposition |
| --- | --- | --- |
| Exact-byte duplicates, type organization, batch file operations | Fileherder | Keep the implementation and conformance tests here. |
| Metadata, alternate hash algorithms, display labels | Shared `utils/file_utils.py` | Preserve its string-return/exception API and category/format semantics. Add matching invalid-chunk validation in that owner. |
| Legacy exact/normalized dedup teaching examples | Snippets `deduplication/file_deduplication.py` | Correct unsafe exactness and deletion claims/behavior; retain provenance and raw intake. |
| Perceptual image review candidates | Snippets `deduplication/pillow_ahash_dedup.py` | Keep separate from exact equality and retain Pillow's caller-configured pixel guard. |

Authored red and blue 8×8 BMPs have equal byte length/resolution but different
SHA-256; the old Snippets heuristic grouped them together. Average hash gives
those different solid colors distance zero. Normalizing `sum=A*B` and `sum=AB`
also produced a false "exact" text group. A path-only cache reused an old hash
after a rewrite. These are concrete review-versus-equality differences.

The private Snippets corrections require current SHA-256 bytes for exact groups,
retain a separate normalized review key, recompute stale path-only hashes, and
preflight/recheck current group identity before unlink. The explicit legacy
`keep_first=False` option still deliberately removes every validated copy;
default behavior retains a keeper. It offers no confirmation, trash or rollback.

Shared's helper had the same zero-chunk empty-hash defect. Its focused fix keeps
the existing API rather than importing Fileherder: labels, formatting and result
types differ. A bounded search found no equivalent Shared batch mutation layer.
No new package or wholesale migration is justified by these overlaps.

## Remaining boundaries and repeat commands

These are best-effort checks, not atomic path reservations. A concurrent or
hostile writer can replace an entry after validation. Ancestor links are not
globally confined; callers choose trusted source/destination roots. Deletion is
permanent, batches can partially succeed, callbacks can interrupt them, and
in-place overwrite can partially fail. Hardlinks are counted as file entries,
so reported waste can overstate actual reclaimable storage. Mount changes,
Windows behavior, crash recovery, sustained large-file workloads and hostile
path races were not tested. Dry-run counts are not a frozen apply journal.

From this checkout with reviewed local dependencies:

```sh
.venv/bin/python -m pytest tests -q -p no:cacheprovider
.venv/minimum/bin/python -m pytest tests -q -p no:cacheprovider
.venv/bin/python -m build --no-isolation --outdir dist/audit-fixed
```

Install the exact private wheel in a clean environment, then run the same suite
from outside the checkout with `python -I -m pytest -c /dev/null --import-mode=importlib`.
Inspect archive members/metadata, source bytes and RECORD digests as well as
running tests. The source still declares version 1.0.2; private patched artifacts
must be identified by their own digest and commit. They must not be confused
with or substituted for the existing public release.

Rollback is a local Git revert of the audit commits in their respective owners.
No owner files were reorganized or deleted, no deployed library was changed,
and no registry rollback is needed. Publication or a versioned release requires
Luke's explicit approval after reviewing this concrete private result.
